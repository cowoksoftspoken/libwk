# Ideas

This folder contains research direction and mid-term roadmap for evolving WK into a next-generation image codec.

Main documents:

- NEXT_GEN_CODEC_ROADMAP.md  
  Phase-by-phase roadmap and dependencies.
- PERCEPTUAL_CONTROL_FIELD.md  
  Initial design for the control field.

Principles:

- ambitious ideas, but gradual execution
- clear dependencies for features
- do not sacrifice correctness
- roadmap evolves with benchmarks and implementation
